1. Background

Pemeriksaan kualitas produk sepatu umumnya dilakukan secara visual oleh manusia. SoleGuard dikembangkan sebagai tugas akhir untuk PT. Tah Sung Hung, produsen sepatu di Brebes, Jawa Tengah, dengan memanfaatkan Computer Vision agar proses pemeriksaan dapat dibantu oleh sistem deteksi otomatis.

2. Problem Statement

Pemeriksaan visual manual berpotensi tidak konsisten dan memakan waktu. Diperlukan sistem yang dapat mengenali jenis cacat pada produk sepatu secara otomatis dari input video dan menampilkannya dalam antarmuka yang mudah digunakan.

3. Project Objectives

  • Membangun model Object Detection berbasis YOLOv26n untuk mendeteksi cacat produk sepatu.
  • Mengintegrasikan model ke aplikasi Streamlit untuk pemeriksaan melalui input video.
